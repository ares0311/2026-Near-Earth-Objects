# NEO Harness Independent Review Contract

Status: `DRAFT_INCOMPLETE`

## Role separation

The reviewer must be a fresh top-level agent. It may inspect and test the exact
canonical harness bytes but may not repair them, implement the project, acquire
scientific data, execute the future harness, or select missing scientific or
product decisions.

## Acceptance question

Can a competent coding agent implement the authorized branches using only the
canonical repository files without inventing an unverified method, equation,
source URL, schema, threshold, business rule, or acceptance decision?

## Required review families

The final review must cover:

- repository and authority identity;
- source URL, metadata, demonstrated-context, and transfer-limit correctness;
- equation completeness, units, domains, uncertainty, and numerical behavior;
- schema completeness, strictness, identity, lineage, and null semantics;
- cross-document and config consistency;
- cutoff safety and future-information leakage;
- denominators, selection functions, calibration, uncertainty, power, and
  multiplicity;
- branch separation and information ceilings;
- business-state transitions, reason codes, retention, and recovery;
- resource and access boundaries;
- coding-agent handoff completeness;
- prohibited scientific, operational, submission, authority, and impact claims.

Each family requires materially novel unsafe attacks and matched legitimate
controls. Passing named historical examples does not close a family.

For every newly researched source claim, the reviewer must independently test at
least one unsafe mutation and one matched legitimate control across the relevant
source identity, metadata, claim-support, context, grade, transfer-limit, and
prohibited-inference dimensions. A URL availability check alone cannot pass.

## Permitted verdicts

- `HARNESS_READY_FOR_CODEX_CLI_HANDOFF`
- `REVISIONS_REQUIRED`

Acceptance applies only to the exact reviewed Git commit and canonical files. It
does not itself authorize implementation, execution, deployment, scientific
claims, submission, or authority contact.
